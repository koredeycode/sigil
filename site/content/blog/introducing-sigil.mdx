# Introducing Sigil

We are thrilled to unveil **Sigil**, an open-source framework for building, managing, and scaling autonomous AI agents on the Solana blockchain.

## Why Sigil?

The transition from "copilots" to "autonomous agents" requires more than just better prompts. It requires a robust architecture that handles:

1. **Reasoning**: Thinking through complex, multi-step tasks.
2. **Tool Execution**: Interacting with real-world APIs and on-chain protocols.
3. **Safety**: Enforcing strict guardrails to prevent unintended actions.

Sigil solves this with our **Tri-Head Architecture**, separating these concerns into specialized modules that work in harmony.

## The Tri-Head Architecture

- **Reasoning Head**: Maps natural language directives to high-level plans.
- **Execution Head**: Handles the underlying tool calls, from swapping tokens to querying databases.
- **Guardrail Head**: Monitors every action against valid safety policies.

## Getting Started

You can start building with Sigil today:

```bash
npm i -g sigil
sigil init
```
