title: CLI Reference
description: Complete command reference for the Sigil Wallet CLI.
---

The Sigil Wallet CLI is the primary management interface for agents, providers, directives, and system configuration.

## Workspace

| Command | Description |
|---|---|
| `sigil init` | Start the step-by-step onboarding wizard |
| `sigil onboard` | Alias for init, runs the setup flow |
| `sigil start` | Boot the API server, Web Dashboard, and all active agent loops |
| `sigil stop` | Halt all running agent intervals gracefully |
| `sigil status` | Show server and agent status |
| `sigil kill` | Emergency halt — stop all signing, wipe keys from memory globally |
| `sigil kill [agent]` | Kill a specific agent by ID |
| `sigil health` | Check database validity and connection health |

## Agent Management

| Command | Description |
|---|---|
| `sigil agent create --name <name>` | Create a new agent with an isolated wallet |
| `sigil agent start <name>` | Launch an agent's reasoning loop |
| `sigil agent pause <name>` | Temporarily stop an agent (key stays in memory) |
| `sigil agent destroy <name>` | Delete an agent and all associated data |
| `sigil agent list` | Show all agents and their current status |
| `sigil agent info <name>` | Show detailed agent info (address, directives, activity, token holdings) |

## Chat, Logs & Transactions

| Command | Description |
|---|---|
| `sigil chat <agent> "<message>"` | Send a message to a specific agent's context window |
| `sigil logs <agent>` | View agent logs (Reasoning, Actions, Errors) |
| `sigil logs <agent> --follow` | Stream real-time logs |
| `sigil logs --all` | View merged logs from all agents simultaneously |
| `sigil tx list <agent>` | View transaction history and swap records |

## Providers (LLM)

| Command | Description |
|---|---|
| `sigil provider add <name>` | Configure a new LLM provider (OpenAI, Anthropic, Ollama, etc) |
| `sigil provider set-primary <name>` | Switch the active provider |
| `sigil provider list` | View all configured providers |
| `sigil provider remove <name>` | Remove a provider |
| `sigil provider models <name> --api-key <key>` | List available models |

## Configuration & Auth

| Command | Description |
|---|---|
| `sigil config set --loop-interval <seconds>` | Adjust global loop timing |
| `sigil auth rotate` | Regenerate the API session token (Requires restart) |

## UI Launchers

| Command | Description |
|---|---|
| `sigil tui` | Launch the interactive terminal dashboard (Ink-based) |
| `sigil dashboard` | Start the Web API and UI server headlessly |

## Examples

### Full onboarding flow

```bash
sigil init
sigil agent create --name "alpha"
sigil agent start "alpha"
sigil logs alpha --follow
```

### Switch LLM provider

```bash
sigil provider add ollama
sigil provider set-primary ollama
```

### Emergency halt

```bash
sigil kill
```
