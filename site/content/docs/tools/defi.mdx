Sigil Wallet agents can interact with real on-chain DeFi protocols on Solana Devnet, enabling autonomous trading, liquidity provision, and portfolio rebalancing.

## Protocol: SPL Token Swap

Sigil Wallet uses the **SPL Token Swap** reference program for on-chain DeFi operations.

### Trading Tools

| Tool | Description |
|---|---|
| `swap_tokens` | Execute a token swap using the Jupiter API aggregator |
| `fetch_price` | Retrieve the USD price for SOL, USDC, or custom tokens |

### Portfolio Tools

| Tool | Description |
|---|---|
| `get_portfolio_snapshot` | Full breakdown of holdings with value percentages |

## Example Scenarios

```text
"Swap 50% of my USDC to SOL if SOL drops below $20"
"Check portfolio allocation every 5 minutes"
"Fetch the current USD price of BONK"
```

## Slippage Protection

All swap operations are subject to **slippage guardrails**:

- Default maximum slippage: **1%**
- If market conditions would cause price deviation beyond the cap, the swap is **blocked**
- The agent logs the block reason and retries on the next loop cycle

## Portfolio Assessment
The portfolio snapshot workflow empowers the agent to reason about asset distribution:
1. `get_portfolio_snapshot` — Agent reads current holdings and percentages
2. The agent uses this snapshot within its LangGraph reasoning step to decide if it should generate a `swap_tokens` intent to simulate rebalancing behavior.

See [Safety & Guardrails](/docs/guardrails) for configuration options.
