title: Directive Engine
description: Define agent behavior with natural language rules.
---

Directives are **natural language rules** that define what an agent should do. Instead of writing code, you describe behavior in plain English and the LLM interprets it against real-time on-chain data.

## How It Works

1. **You define a rule** — e.g., *"Request an airdrop if my SOL balance drops below 1"*
2. **Agent loads context** — On each loop cycle, the agent gathers its balances, holdings, and transaction history
3. **LLM evaluates** — The directives are passed to the model alongside the current state
4. **Action is proposed** — If a directive triggers, the LLM generates a tool call
5. **Guardrails validate** — The proposed action is checked against safety limits
6. **Execution** — If approved, the transaction is signed and submitted

## Managing Directives

### Add a Directive

```bash
sigil directive add --agent "alpha" \
  --condition "If my SOL balance is below 1" \
  --action "Request an airdrop"
```

### List Directives

```bash
sigil directive list --agent "alpha"
```

### Toggle a Directive

```bash
sigil directive toggle --agent "alpha" --id 1
```

### Remove a Directive

```bash
sigil directive remove --agent "alpha" --id 1
```

## Structured Fields

While directives are written in natural language, they are stored with structured metadata:

| Field | Description | Example |
|---|---|---|
| `condition` | The trigger rule in plain English | "If SOL balance is below 1" |
| `action` | The desired response | "Request an airdrop" |
| `maxAmount` | Hard cap on the action value | "10% of portfolio" |
| `cooldown` | Minimum time between executions | "1 hour" |
| `isActive` | Enable/disable toggle | `true` |

## Example Directives

```text
"Request an airdrop if my SOL balance is less than 1"
"Swap 50% of my USDC to SOL if SOL drops below $20"
"Close any token account with zero balance"
"Mint 1000 DEMO tokens every day at 9am"
"Only rebalance if portfolio drift exceeds 5%"
```

## Why Natural Language?

Natural language directives allow **non-deterministic reasoning**. For example:

> *"Only rebalance my portfolio if SOL feels undervalued relative to USDC"*

The LLM can interpret "undervalued" using context that fixed code cannot — price trends, volume patterns, and relative momentum. The Guardrails layer still enforces hard limits on any resulting action.
