---
title: CLI Reference
description: Complete command reference for the Sigil CLI.
---

The Sigil CLI is the primary management interface for agents, providers, directives, and system configuration.

## Workspace

| Command | Description |
|---|---|
| `sigil init` | Start the step-by-step onboarding wizard |
| `sigil start` | Boot the API server and all active agent loops |
| `sigil stop` | Halt all agents and shut down the server |
| `sigil status` | Show server and agent status |
| `sigil kill` | Emergency halt — stop all signing, wipe keys from memory |
| `sigil kill <agent>` | Kill a specific agent |

## Agent Management

| Command | Description |
|---|---|
| `sigil agent create --name <name>` | Create a new agent with an isolated wallet |
| `sigil agent start <name>` | Launch an agent's reasoning loop |
| `sigil agent pause <name>` | Temporarily stop an agent (key stays in memory) |
| `sigil agent destroy <name>` | Delete an agent and all associated data |
| `sigil agent list` | Show all agents and their current status |
| `sigil agent info <name>` | Show detailed agent info (address, directives, activity) |

## Chat & Logs

| Command | Description |
|---|---|
| `sigil chat <agent> "<message>"` | Send a message to a specific agent |
| `sigil logs <agent>` | View agent logs |
| `sigil logs <agent> --follow` | Stream real-time logs |
| `sigil logs --all` | View merged logs from all agents |
| `sigil tx list <agent>` | View transaction history |

## Directives

| Command | Description |
|---|---|
| `sigil directive add --agent <name>` | Add a new directive (interactive) |
| `sigil directive list --agent <name>` | List all directives for an agent |
| `sigil directive toggle --agent <name> --id <id>` | Enable/disable a directive |
| `sigil directive remove --agent <name> --id <id>` | Remove a directive |

## Providers

| Command | Description |
|---|---|
| `sigil provider add <name>` | Configure a new LLM provider |
| `sigil provider set-primary <name>` | Switch the active provider |
| `sigil provider list` | View all configured providers |
| `sigil provider remove <name>` | Remove a provider |
| `sigil provider models <name> --api-key <key>` | List available models |

## Configuration

| Command | Description |
|---|---|
| `sigil config set --loop-interval <seconds>` | Adjust global loop timing |
| `sigil auth rotate` | Regenerate the API session token |

## UI Launchers

| Command | Description |
|---|---|
| `sigil tui` | Launch the interactive terminal dashboard |
| `sigil start` | Start the API server (Web Dashboard at `:74446`) |

## Examples

### Full onboarding flow

```bash
sigil init
sigil agent create --name "alpha"
sigil agent start "alpha"
sigil directive add --agent "alpha" \
  --condition "If SOL balance is below 1" \
  --action "Request an airdrop"
sigil logs alpha --follow
```

### Switch LLM provider

```bash
sigil provider add ollama
sigil provider set-primary ollama
```

### Emergency halt

```bash
sigil kill
```
