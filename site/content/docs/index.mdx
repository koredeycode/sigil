# Sigil

**Sigil** is a developer-first, autonomous wallet interface that lives on your local machine. It allows users to spawn **multiple independent AI agents**, each with its own wallet, directives, and thought loop — all managed from a single system.

Unlike traditional wallets that are "dead" until clicked, Sigil is **alive**. Each agent runs a continuous "Thought Loop," monitoring balances, executing conditional transfers, managing SPL tokens, and rebalancing holdings while you sleep — all while keeping private keys explicitly secured in your OS Keychain.

## The Tri-Head Architecture

Sigil operates through three primary interfaces, all synchronized in real-time:

1.  **The TUI (Terminal UI):** A rich, interactive terminal dashboard built with Ink.
2.  **The CLI:** For headless operation, scripting, and cron-based automation.
3.  **The Dashboard (Web UI):** A local visual interface to chat with agents and manage directives.

## Core Value Pillars

*   **Provider Agnostic:** Support for 10+ LLM providers.
*   **Local Sovereignty:** SQLite database and Keychain storage. No cloud dependencies.
*   **Synchronized State:** Real-time event stream via WebSockets.
*   **Guardrails-First:** Hard-coded safety layers independent of the LLM.
