This guide walks you through creating and running your first autonomous agent.

## 1. Initialize Your Workspace

```bash
sigil init
```

The wizard will prompt you to:
- Choose an LLM provider (e.g., OpenAI, Anthropic, Ollama)
- Enter your API key
- Select a default model

Once complete, Sigil Wallet creates a local SQLite database at `~/.sigil/sigil.db` and generates a session token for API authentication.

## 2. Create an Agent

```bash
sigil agent create --name "alpha"
```

This generates:
- A new **Ed25519 keypair** stored securely in your OS Keychain
- An isolated entry in the SQLite database for this agent's data
- A Solana Devnet wallet address

## 3. Start the Agent

```bash
sigil agent start "alpha"
```

The agent begins its reasoning loop:

1. **Fetch** — Reads SOL balance, SPL token holdings, and recent transactions
2. **Evaluate** — Passes context to the LLM
3. **Validate** — Proposed actions are checked against Guardrails
4. **Execute** — Approved transactions are signed and submitted to Devnet
5. **Log** — Reasoning traces are saved to the local database

## 4. Monitor Activity

View real-time logs:

```bash
sigil logs alpha --follow
```

Or launch the interactive terminal dashboard:

```bash
sigil tui
```

Or start the web dashboard:

```bash
sigil start
```

Then open `http://localhost:7445` in your browser.
