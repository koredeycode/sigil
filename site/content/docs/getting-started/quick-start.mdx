# Quick Start

Sigil is the easiest way to build autonomous agents on Solana.

## Installation

Install the CLI globally:

```bash
npm i -g sigil
```

## Initialization

Create a new workspace:

```bash
sigil init
```

## Creating Your First Agent

Create a simple trading agent:

```bash
sigil agent create --name "jarvis"
```

## Running the Agent

Start the agent:

```bash
sigil agent start jarvis
```
